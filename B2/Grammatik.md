## 2. Der grammatikalische B2-Kanon (Die Meilensteine)

| Thema | Funktion & Bildungsweise | Typisches B2-Beispiel |
| :--- | :--- | :--- |
| **Nominalstil vs. Verbalstil** | Umwandlung von Nebensätzen in Präpositionalgefüge | *Beim Betreten des Raumes...* (statt: *Als wir den Raum betraten...*) |
| **Passiversatzformen** | Alternativen zum Passiv (*sein + zu*, *sich lassen*, *-bar*) | *Das Problem **lässt sich nicht leugnen**.* (= kann nicht geleugnet werden) |
| **Zustandspassiv** | Beschreibt das Resultat/den Zustand (*sein + Partizip II*) | *Das Fenster **ist geöffnet**.* (Resultat des Vorgangs) |
| **Funktionsverbgefüge (FVG)** | Nomen + festes Funktionsverb für formellen Stil | *zur Verfügung stehen, in Betracht ziehen, Maßnahmen ergreifen* |
| **Futur II als Vermutung** | Vermutung über eine vergangene Handlung (*wird ... haben/sein*) | *Er ist nicht da; er **wird wohl den Zug verpasst haben**.* |
| **Partizip I & II als Attribute** | Partizip I (Aktiv: *-end*) & Partizip II (Passiv: *ge-...-t/-en*) | *die **steigenden** Energiepreise* / *die **beschlossenen** Gesetze* |
| **Erweiterte Partizipialgruppen** | Mehrgliedrige Attributphrasen vor dem Nomen | *die **vom Parlament gestern verabschiedeten** Gesetze* |
| **Doppelkonnektor *je... desto/umso*** | Proportionale Bedingung (Inversion im Folgesatz!) | *Je früher wir beginnen, **desto schneller sind** wir fertig.* |
| **Irrealis der Vergangenheit** | Konjunktiv II der Vergangenheit (*hätte/wäre + Partizip II*) | *Hätte ich das gewusst, **wäre** ich nicht hingegangen.* |
| **Subjektloses Passiv** | Handlungsfokus ohne konkretes Subjekt | *Am Wochenende **wird nicht gearbeitet**.* / *Ihm **wurde geholfen**.* |

## 3. Satzstruktur & Textarchitektur (Syntax auf Stufe B2)

### A. Die Transformationsmatrix: Verbalstil <-> Nominalstil

Die Beherrschung dieser Transformation ist das Aushängeschild jedes B2/C1-Sprechers:

| Logische Relation | Verbalstil (Nebensatz) | Nominalstil (Präposition + Kasus) |
| :--- | :--- | :--- |
| **Kausal (Grund)** | *weil / da* (+ Verb am Ende) | **Wegen / Aufgrund / Infolge** (+ Genitiv) |
| | *Weil die Nachfrage sank,...* | *Aufgrund des Nachfragerückgangs...* |
| **Konzessiv (Gegengrund)** | *obwohl / obgleich* (+ Verb am Ende) | **Trotz / Ungeachtet** (+ Genitiv) |
| | *Obwohl er krank war,...* | *Trotz seiner Krankheit...* |
| **Temporal (Zeit)** | *während / als / nachdem* | **Während / Bei / Nach** (+ Genitiv / Dativ) |
| | *Nachdem die Sitzung beendet war,...* | *Nach Beendigung der Sitzung...* |
| **Konditional (Bedingung)**| *wenn / falls* (+ Verb am Ende) | **Bei / Im Falle** (+ Dativ / Genitiv) |
| | *Falls die Maschine ausfällt,...* | *Bei einem Ausfall der Maschine...* |
| **Final (Zweck)** | *damit / um ... zu* | **Zu / Zum Zwecke / Zwecks** (+ Dativ / Genitiv) |
| | *Damit die Daten geschützt werden,...* | *Zum Schutz der Daten...* |

### B. Die Passiversatzformen (Eleganz ohne Passiv-Monotonie)

Im Deutschen wirkt ein Text schwerfällig, wenn jeder zweite Satz mit *werden* konstruiert ist. Nutze diese 4 Alternativen:

```
                               ┌────────────────────────────────┐
                               │       Passivbedeutung:         │
                               │  "Das Auto kann repariert      │
                               │   werden."                     │
                               └───────────────┬────────────────┘
                                               │
      ┌────────────────────┬───────────────────┴───────────────────┬───────────────────┐
      ▼                    ▼                                       ▼                   ▼
┌──────────────┐     ┌──────────────┐                        ┌──────────────┐    ┌──────────────┐
│ sich lassen  │     │  sein + zu + │                        │ Adjektiv auf │    │ gerundivähn- │
│  + Infinitiv │     │  Infinitiv   │                        │ -bar / -lich │    │ liche Formen │
├──────────────┤     ├──────────────┤                        ├──────────────┤    ├──────────────┤
│ "Das Auto    │     │ "Das Auto    │                        │ "Das Auto    │    │ "Das zu      │
│  lässt sich  │     │  ist leicht  │                        │  ist leicht  │    │  reparierende│
│  reparieren."│     │  zu repa-    │                        │  reparierbar.│    │  Auto..."    │
│              │     │  rieren."    │                        │              │    │              │
└──────────────┘     └──────────────┘                        └──────────────┘    └──────────────┘
```

> **Achtung bei *sein + zu + Infinitiv*:**  
> Je nach Kontext drückt es eine **Möglichkeit** (*können*) oder eine **Notwendigkeit** (*müssen/sollen*) aus:  
> - *Diese Aufgabe **ist sofort zu erledigen**.* (= muss erledigt werden!)  
> - *Das Problem **ist schwer zu verstehen**.* (= kann nur schwer verstanden werden).

### C. Erweiterte Partizipialattribute entschlüsseln

In deutschen Fachtexten, Zeitungsberichten und Fachaufsätzen findest du häufig sogenannte Klammer-Attribute:

```
                  ┌────────────── Partizipialklammer ──────────────┐
  Artikel         │ Vorangestellte Ergänzungen & Angaben           │ Partizip      │ Bezugsnomen
┌───────────────┬─┴────────────────────────────────────────────────┼───────────────┼──────────────┐
│ Die           │ vom Aufsichtsrat gestern einstimmig              │ beschlossene  │ Fusion...    │
│ Ein           │ seit Monaten ununterbrochen                      │ steigender    │ Aktienkurs...│
└───────────────┴──────────────────────────────────────────────────┴───────────────┴──────────────┘
```
**Wie liest man das?**  
1. Springe vom Artikel (*Die*) sofort zum Bezugsnomen (*Fusion*).  
2. Lies das Partizip (*beschlossene*).  
3. Lies die Füllinformationen im Zwischenraum (*vom Aufsichtsrat gestern einstimmig*).

## 4. Wortgebrauch: Funktionsverbgefüge (Nomen-Verb-Kollokationen)

Im B2-Register ersetzen FVG einfache Verben:

| Einfaches Verb | Funktionsverbgefüge | Beispielsatz |
| :--- | :--- | :--- |
| anwenden | **zur Anwendung kommen** | *Die neue Verordnung kommt ab Mai zur Anwendung.* |
| beantragen | **einen Antrag stellen auf** | *Wir müssen einen Antrag auf Verlängerung stellen.* |
| beeinflussen | **Einfluss ausüben auf (+ Akk)** | *Lobbyisten versuchen, Einfluss auf die Politik auszuüben.* |
| beenden | **zu Ende bringen / führen** | *Wir sollten die Diskussion nun zu Ende bringen.* |
| erwägen | **in Betracht ziehen** | *Wir ziehen verschiedene Optionen in Betracht.* |
| bezweifeln | **in Zweifel ziehen** | *Niemand zieht seine Kompetenz in Zweifel.* |
| verfügen über | **zur Verfügung stehen / stellen** | *Die Mittel stehen uns ab sofort zur Verfügung.* |

## 5. Häufige B2-Stolpersteine & Dozenten-Tipps

- ⚠️ **Fehler 1: Wortstellung nach *je... desto/umso*.**  
  *Falsch:* ❌ *Je mehr ich lerne, desto ich spreche besser.*  
  *Richtig:*  *Je mehr ich lerne, **desto besser spreche ich**.*  
  *(Im Je-Satz steht das Verb am Ende, im Desto-Satz steht das Komparativ-Adjektiv direkt mit dem Verb auf Position 1/2: Inversion!).*
- ⚠️ **Fehler 2: Falscher Kasus nach anspruchsvollen Präpositionen.**  
  *Falsch:* ❌ *Trotz dem schlechten Wetter (Umgangssprache).*  
  *Richtig:*  *Trotz **des schlechten Wetters** (Genitiv ist Standard auf B2!).*
- ⚠️ **Fehler 3: Konjunktiv II der Vergangenheit ohne doppeltes Hilfsverb.**  
  *Falsch:* ❌ *Wenn ich hätte gekonnt kommen...*  
  *Richtig:*  *Wenn ich **hätte kommen können** (Ersatzinfinitiv am Satzende!).*

## 6. Dein täglicher B2-Trainingsplan (Der Baukasten)

1. **Stil-Transformation:** Nimm 2 Sätze im Verbalstil aus einer Zeitung und transformiere sie in prägnanten **Nominalstil** mit Genitivpräpositionen (*aufgrund, infolge, ungeachtet*).
2. **FVG-Drill:** Wähle 3 Nomen-Verb-Verbindungen aus [`Verbs.md`](file:///e:/Projects/VS_Projects/DeutscheLernen/B2/Verbs.md) und bilde geschäftliche Mustersätze für den Beruf.
3. **Passiversatz:** Bilde einen Satz mit *sich lassen* und einen Satz mit *sein + zu + Infinitiv*.
