## 2. Der grammatikalische A2-Kanon (Die Meilensteine)

| Grammatik-Thema | Kernkompetenz | Musterbeispiel |
| :--- | :--- | :--- |
| **Das Perfekt** | Erzählen in der Vergangenheit (*haben/sein* + Partizip II) | *Ich **habe** ein Buch **gelesen**.* / *Er **ist** nach Berlin **gefahren**.* |
| **Präteritum (Grundverben)** | *sein*, *haben*, Modalverben im Präteritum | *Ich **war** krank und **musste** zu Hause bleiben.* |
| **Der Dativ (Wem-Fall)** | Indirektes Objekt & feste Dativ-Verben | *Ich helfe **dem** Mann.* / *Das gefällt **mir**.* |
| **Wechselpräpositionen** | 9 Präpositionen (Dativ = Wo? / Akkusativ = Wohin?) | *Das Buch liegt **auf dem** Tisch (Wo?).* / *Ich lege es **auf den** Tisch (Wohin?).* |
| **Dativpräpositionen** | *aus, bei, mit, nach, seit, von, zu* | *Ich fahre **mit dem** Bus **zur** Arbeit.* |
| **Nebensätze (*weil, dass, wenn*)** | Konjunktionen, die das Verb ans Satzende verbannen | *Ich lerne, **weil** ich in Deutschland arbeiten **möchte**.* |
| **Hauptsatzverbinder (ADUSO)** | Position-0-Konnektoren (keine Auswirkung auf Verbposition) | *Er will kommen, **aber** er hat keine Zeit.* |
| **Adjektivdeklination** | Endungen nach bestimmtem (*-e / -en*) & unbestimmtem Artikel | *Der neu**e** Kollege kauft ein schnell**es** Auto.* |
| **Komparation der Adjektive** | Grundform -> Komparativ (`-er`) -> Superlativ (`am ...-sten`) | *schnell -> schnell**er als** -> **am** schnell**sten**.* |
| **Reflexive Verben** | Handlungen, die sich auf das Subjekt zurückbeziehen | *Ich freue **mich** auf das Wochenende.* |
| **Indirekte Fragesätze** | Höfliche Fragen mit *ob* oder Fragewörtern | *Können Sie mir sagen, **wo** der Bahnhof **ist**?* |

## 3. Satzstruktur & Wortstellung (Syntax auf Stufe A2)

### A. Die Perfekt-Klammer
Im Perfekt bilden das Hilfsverb (*haben* oder *sein*) und das Partizip II eine unzertrennliche Klammer um den gesamten Mittelfeldsatz:

```
  Position 1        Hilfsverb (Pos. 2)     Mittelfeld                  Partizip II (Ende)
┌─────────────────┬──────────────────────┬───────────────────────────┬────────────────────┐
│ Wir             │ haben                │ gestern bis spät abends   │ gearbeitet.        │
│ Meine Schwester │ ist                  │ am Montag nach Wien       │ geflogen.          │
│ Vorhin          │ habe                 │ ich meine Schlüssel       │ gefunden.          │
└─────────────────┴──────────────────────┴───────────────────────────┴────────────────────┘
```

> **Wann *haben*, wann *sein*?**  
> - **sein**: Bei Ortswechsel (*gehen, fahren, fliegen*), Zustandswechsel (*einschlafen, aufwachen, sterben*) sowie *sein, werden, bleiben*.  
> - **haben**: Bei allen transitiven Verben (die ein Akkusativobjekt haben) und bei allen Handlungen ohne Orts-/Zustandswechsel (*arbeiten, schlafen, essen*).

---

### B. Die zwei Typen von Satzverbindern (Konnektoren)

#### 1. Die ADUSO-Konnektoren (Position 0):
Verbinden zwei Hauptsätze. Sie zählen syntaktisch als **Position 0**. Die reguläre V2-Stellung im folgenden Satz bleibt unangetastet:
- **A**ber (but)
- **D**enn (because)
- **U**nd (and)
- **S**ondern (but rather)
- **O**der (or)

```
  Hauptsatz 1            Pos. 0        Pos. 1 (Subjekt)    Pos. 2 (Verb)     Rest
┌──────────────────────┬─────────────┬───────────────────┬─────────────────┬──────────┐
│ Ich lerne Deutsch,   │ aber        │ mein Bruder       │ lernt           │ Spanisch.│
│ Wir beeilen uns,     │ denn        │ der Zug           │ kommt           │ gleich.  │
└──────────────────────┴─────────────┴───────────────────┴─────────────────┴──────────┘
```

#### 2. Subordinierende Konjunktionen (*weil, dass, wenn, ob* -> Verb ans Ende!):
Leiten einen Nebensatz ein. Das konjugierte Verb wird an das **allerletzte Ende** des Nebensatzes katapultiert!

```
  Hauptsatz                  Konjunktion    Subjekt     Mittelfeld          Verb am ENDE
┌──────────────────────────┬──────────────┬───────────┬───────────────────┬──────────────┐
│ Ich bleibe im Bett,      │ weil         │ ich       │ heute krank       │ **bin**.     │
│ Er hat gesagt,           │ dass         │ er        │ morgen nach Hause │ **kommt**.   │
│ Ruf mich bitte an,       │ wenn         │ du        │ am Bahnhof        │ **bist**.    │
└──────────────────────────┴──────────────┴───────────┴───────────────────┴──────────────┘
```

### C. Reihenfolge der Objekte im Satz (Dativ vor Akkusativ)

Wenn ein Satz zwei Nomen als Objekte enthält (z. B. bei *geben, schenken, zeigen*), gilt die eiserne Regel:  
👉 **Der Dativ (die Person) steht vor dem Akkusativ (der Sache)!**

- *Ich schenke **meiner Mutter** (Dativ / Person) **ein Buch** (Akkusativ / Sache).*
- *Der Lehrer erklärt **den Schülern** (Dativ) **die Grammatik** (Akkusativ).*

## 4. Wortgebrauch: Die Wechselpräpositionen (Wo vs. Wohin)

Neun Präpositionen können entweder mit Dativ oder mit Akkusativ stehen:  
**an, auf, hinter, in, neben, über, unter, vor, zwischen**

```
                  ┌──────────────────────────────────────────────┐
                  │            Wechselpräpositionen              │
                  └──────────────┬───────────────────────────────┘
                                 │
                 ┌───────────────┴───────────────┐
                 ▼                               ▼
       Frage: WO? (Position)          Frage: WOHIN? (Bewegung/Ziel)
       -> KASUS: DATIV                 -> KASUS: AKKUSATIV
       Verben: liegen, stehen,        Verben: legen, stellen,
               sitzen, hängen                  setzen, hängen
       "Das Buch liegt                "Ich lege das Buch
        AUF DEM Tisch."                AUF DEN Tisch."
```

## 5. Häufige A2-Stolpersteine & Dozenten-Tipps

- ⚠️ **Fehler 1: Verbposition im *weil*-Satz vergessen.**  
  *Falsch:* ❌ *Ich lerne Deutsch, weil ich möchte in München leben.*  
  *Richtig:*  *Ich lerne Deutsch, weil ich in München leben **möchte**.* (Das Hilfs-/Modalverb steht am Satzende!).
- ⚠️ **Fehler 2: Falsches Hilfsverb im Perfekt bei Bewegungsverben.**  
  *Falsch:* ❌ *Ich habe nach Hause gegangen.*  
  *Richtig:*  *Ich **bin** nach Hause gegangen.*
- ⚠️ **Fehler 3: Dativ-Plural-Endung `-n` am Nomen unterschlagen.**  
  *Falsch:* ❌ *Ich helfe den Kind... / den Freunde...*  
  *Richtig:*  *Ich helfe den Kinder**n** / den Freunde**n**.* (Im Dativ Plural erhalten alle Nomen ein `-n`, sofern sie nicht auf `-s` enden).
