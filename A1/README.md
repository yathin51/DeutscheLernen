# A1 - Beginner (Anfänger)

Welcome to the A1 level resources. This folder contains learning materials, vocabulary, grammar notes, and exercises for absolute beginners starting their German language journey.

## Master Grammar Guide
- 📖 [**A1 Grammatik-Leitfaden (Grammatik.md)**](./Grammatik.md) — Comprehensive pedagogical master guide on syntax, sentence brackets (*Satzklammer*), verb positions, case usage, and how to combine all files in this level.

## Core Topics
- **Greetings & Introductions**: Saying hello, introducing yourself, and asking others basic questions.
- **Numbers, Time, & Dates**: Counting, telling time, and talking about days of the week or months.
- **Everyday Life**: Shopping, ordering food, talking about hobbies, and describing your home.
- **Basic Grammar**:
  - Present tense conjugation (*Präsens*)
  - Personal pronouns (*ich, du, er, sie, es...*)
  - Nominative and Accusative cases
  - Sentence structure (subject-verb-object)
